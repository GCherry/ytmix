3. Smart Video Rendering Architecture (4 Execution Paths)

        The active path highlights based on your flag selection above
      


      

        
        

          

            Path A
            ~5 Sec / Hour
          

          
Video Loop + No Overlays

          

            Pre-normalizes the short `.mp4`/`.mov`/`.gif` loop once to `1920x1080` (`setsar=1`, `yuv420p`), then muxes with `-stream_loop -1 -c:v copy`.
          

          

            
• Input: .mp4 / .mov / .gif

            
• Overlays: Disabled

            
• Video Codec: -c:v copy

          

        


        
        

          

            Path B
            HW Accelerated
          

          
Video Loop + Burned Titles

          

            Burns dynamic `.ass` subtitles (`\fad(500,500)`) over the looping video using `h264_videotoolbox` (macOS), `h264_nvenc`, or `libx264`.
          

          

            
• Input: .mp4 / .mov / .gif

            
• Overlays: Enabled (.ASS Filter)

            
• Video Codec: DetectEncoder

          

        


        
        

          

            Path C
            Low-FPS Still Tune
          

          
Static Artwork Mode

          

            Uses `-loop 1 -tune stillimage` at `2 fps` (or `10 fps` with `.ass` overlays) so `libx264` processes up to 93% fewer frames.
          

          

            
• Input: .png / .jpg / .webp

            
• Framerate: 2 fps (or 10 fps w/ text)

            
• Video Codec: libx264 -tune stillimage

          

        


        
        

          

            Path D
            Auto Visualizer
          

          
14 Presets + Sleep Modes

          

            Selected whenever `--bg` is omitted. Uses FFmpeg audio-to-video filters (14 presets, 7 Color Themes, brightness/fade/dim-titles) or `#000000` `2 fps` blackout.
          

          

            
• Input: merged_audio.m4a (no --bg)

            
• Dark / Sleep: 5 presets + fade/dimmer

            
• Preflight: DetectFilters()

          

        

      

    


    
    

      

        
4. Package Dependency Graph & Embedded Studio (`ytmix ui`)

        Acyclic pure-Go packages (minimal vetted deps)
      

      

        

          
Package Ownership & Imports

          
cmd/ytmix ──> internal/mixer, internal/ui, internal/render

          
internal/ui ──> internal/mixer, internal/render, internal/subtitle

          
internal/mixer ──> probe, audio, subtitle, render

          
Leaf packages (`probe`, `subtitle`, `render`) never import internal packages; `audio` imports `probe` only.

        

        

          
Editorial Mix Studio (Variant A)

          
• Auto Visualizer Tab: Category chips (`All`, `Dark / Sleep`, `Spectrum`, `Wave & 3D`, `Meters`), 6-card 3×2 pager (`◀`/`▶` + dots), 7 Color Themes.

          
• 60fps Stage & Auditioning: Live HTML5 `<canvas>` renderers + Web Audio `AnalyserNode` over `GET /api/sessions/{id}/tracks/{tid}/audio`.

          
• LAN-Safe Path D: `bgMode: "visualizer"` works across LAN (`0.0.0.0`) while keeping local filesystem path inputs gated (`403`).
